# Portafolio personal React + TypeScript + Vite

Portafolio web personal desarrollado para presentar mi perfil profesional,
experiencia, formación, habilidades técnicas y proyectos de desarrollo de
software.

El proyecto busca ofrecer una experiencia moderna, profesional, responsive y
accesible, siguiendo buenas prácticas actuales de desarrollo web.

## Tecnologías

- React
- TypeScript
- Vite
- HTML5
- CSS3
- Git / GitHub
- Netlify
