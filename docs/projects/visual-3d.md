# Sistema de Visualización 3D y Detección de Colisiones

## Categoría
Software / Gráficos 3D

## Tecnologías
- C#
- OpenTK
- OpenGL

## Descripción Corta

Aplicación 3D desarrollada en C# y OpenTK para renderizar modelos PLY y
detectar colisiones entre una esfera móvil y modelos tridimensionales
mediante una estructura espacial Octree.

## Descripción

Aplicación desarrollada en C# utilizando OpenTK 1.1 para la carga y
renderizado de modelos tridimensionales en formato PLY. El proyecto
implementa detección de colisiones entre una esfera móvil y un modelo 3D
utilizando subdivisión espacial basada en Octree.

La aplicación incorpora diferentes herramientas de visualización para
facilitar la interacción y el análisis de las colisiones, incluyendo
visualización de hitboxes, múltiples perspectivas de cámara y renderizado
gráfico en tiempo real.
## Características

- Carga y renderizado de modelos PLY
- Detección de colisiones
- Subdivisión espacial Octree
- Visualización de hitboxes
- Múltiples cámaras
- Renderizado en tiempo real
