# Space Game

## Categoría

Desarrollo de Juegos / Gráficos 2D

## Tecnologías

- C#
- OpenTK
- OpenGL

## Descripción Corta

Videojuego desarrollado en C# inspirado en un clásico juego espacial, con
gráficos retro renderizados mediante vértices y líneas, diferentes tipos de
enemigos, animaciones y un jefe final.

## Descripción

Space Game es un videojuego desarrollado en C# con una estética retro basada
en pixel art. El jugador controla una nave espacial y debe enfrentarse a
oleadas de enemigos que se aproximan.

El juego incorpora tres tipos de aliens, cada uno con diferentes animaciones
de movimiento, además de un jefe final con mayor dificultad y un
comportamiento especial.

Los elementos gráficos son representados mediante vértices y líneas,
creando una estética visual inspirada en los videojuegos clásicos.

## Características

- Gráficos renderizados mediante vértices y líneas
- Nave espacial controlada por el jugador
- Tres tipos de enemigos
- Animaciones de movimiento para los enemigos
- Jefe final con mayor dificultad
- Estética retro inspirada en pixel art
- Mecánicas de combate y supervivencia

## Mecánicas

El jugador controla una nave espacial para enfrentarse a diferentes oleadas
de aliens. Cada tipo de enemigo presenta un patrón de animación diferente,
mientras que el jefe final introduce un desafío adicional mediante un
comportamiento especial.
