# Backend .NET con Clean Architecture

## Categoría

Backend / APIs / Arquitectura de Software

## Tecnologías

- .NET
- C#
- Entity Framework
- REST API

## Descripción Corta

Backend desarrollado con .NET siguiendo principios de Clean Architecture,
Entity Framework y una API REST para gestionar operaciones CRUD y registrar
la actividad de los usuarios.

## Descripción

Backend desarrollado en .NET siguiendo los principios de Clean Architecture,
con Entity Framework como ORM para la persistencia de datos.

La aplicación utiliza la entidad Persona como componente principal y
proporciona operaciones CRUD para su creación, actualización, consulta y
eliminación. También incorpora el registro de entradas y salidas de sesión
mediante la funcionalidad Visits, permitiendo realizar un seguimiento de la
actividad de los usuarios.

## Características

- Implementación de Clean Architecture
- API REST
- Operaciones CRUD sobre la entidad Persona
- Persistencia de datos mediante Entity Framework
- Registro de entradas y salidas de sesión
- Seguimiento de actividad mediante Visits
- Separación de responsabilidades entre capas

## Arquitectura

El proyecto organiza la aplicación mediante los principios de Clean
Architecture, manteniendo una separación clara entre las diferentes capas
del sistema.

Entity Framework se utiliza como ORM para gestionar la persistencia de
datos, mientras que la API REST proporciona una interfaz para la interacción
con clientes externos.
