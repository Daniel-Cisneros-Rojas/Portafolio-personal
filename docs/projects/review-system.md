# Sistema de Reseñas y Notificaciones

## Categoría

Desarrollo Web / Backend

## Tecnologías

- PHP
- MySQL
- PHPMailer
- HTML
- CSS
- JavaScript

## Descripción Corta

Aplicación web desarrollada en PHP y MySQL que permite crear reseñas y
comentarios sobre contenido cultural, incorporando autenticación mediante
correo electrónico y un sistema de notificaciones con PHPMailer.

## Descripción

Sistema web desarrollado en PHP con una base de datos MySQL e integración
de la librería PHPMailer para la gestión de comunicaciones por correo
electrónico.

La plataforma permite a los usuarios registrarse y validar sus cuentas
mediante códigos de activación únicos con tiempo de expiración enviados a
su correo electrónico. Una vez registrados, pueden crear reseñas sobre
películas, libros y series, así como interactuar mediante comentarios.

El sistema también incorpora notificaciones por correo electrónico que
informan a los usuarios cuando reciben nuevos comentarios en sus reseñas,
facilitando la comunicación y participación dentro de la plataforma.

## Características

- Registro y validación de cuentas mediante correo electrónico
- Códigos de activación únicos con tiempo de expiración
- Creación y gestión de reseñas
- Reseñas sobre películas, libros y series
- Sistema de comentarios entre usuarios
- Notificaciones por correo electrónico
- Integración con PHPMailer
- Persistencia de información mediante MySQL

## Arquitectura

La aplicación utiliza PHP como tecnología principal para la lógica del
sistema y MySQL para la gestión de datos. PHPMailer se integra para gestionar
el envío de correos electrónicos relacionados con la activación de cuentas
y las notificaciones de nuevos comentarios.
