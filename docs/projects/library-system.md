# Sistema de Préstamos Bibliotecarios

## Categoría

Desarrollo Web / Gestión de Datos

## Tecnologías

- PHP
- SQL
- Apache
- XAMPP

## Descripción Corta

Sistema web desarrollado en PHP y SQL para gestionar usuarios, libros y
préstamos bibliotecarios, proporcionando herramientas para consultar,
registrar y controlar los registros de la biblioteca.

## Descripción

Sistema de gestión de préstamos bibliotecarios desarrollado en PHP con
integración a una base de datos SQL. La aplicación permite administrar
usuarios, libros y préstamos mediante una interfaz web orientada a facilitar
la consulta y el control de los registros.

El sistema incorpora un acceso diferenciado para administradores, quienes
pueden utilizar las funcionalidades de gestión disponibles dentro de la
plataforma.

## Características

- Gestión de usuarios
- Gestión de libros
- Registro y control de préstamos
- Consulta de registros
- Funcionalidades específicas para administradores
- Interfaz web para la gestión de la biblioteca
- Conexión con base de datos SQL

## Arquitectura

La aplicación utiliza PHP para implementar la lógica del sistema y una base
de datos SQL para almacenar y gestionar la información relacionada con
usuarios, libros y préstamos.

El proyecto puede ejecutarse mediante un entorno Apache utilizando XAMPP.
