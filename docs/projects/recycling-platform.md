# Plataforma de Reciclaje Inteligente

## Categoría

Machine Learning / Desarrollo Web / Gamificación

## Tecnologías

- React
- TensorFlow

## Descripción Corta

Plataforma web que utiliza TensorFlow para clasificar automáticamente
residuos según su tipo de material y asignarlos al contenedor correspondiente,
incorporando un sistema de recompensas basado en gamificación.

## Descripción

Plataforma web desarrollada para facilitar la correcta clasificación de
residuos mediante un sistema de reconocimiento automático basado en
TensorFlow.

El sistema clasifica los residuos según su tipo de material y determina el
contenedor correspondiente. Además, incorpora un sistema de recompensas
basado en gamificación que asigna puntos a los usuarios, incentivando su
participación y promoviendo hábitos de reciclaje.

## Características

- Clasificación automática de residuos mediante TensorFlow
- Identificación de residuos según su tipo de material
- Asignación del residuo al contenedor correspondiente
- Sistema de puntos y recompensas
- Gamificación orientada al reciclaje
- Interfaz web desarrollada con React

## Machine Learning

El proyecto integra TensorFlow para realizar la clasificación automática
de los residuos a partir de su tipo de material.

El modelo permite incorporar la clasificación como parte del flujo de la
aplicación web, conectando el procesamiento mediante Machine Learning con
la experiencia interactiva del usuario.

## Gamificación

El sistema incorpora un mecanismo de recompensas basado en puntos para
incentivar la participación de los usuarios y fomentar hábitos sostenibles
mediante una experiencia interactiva.
