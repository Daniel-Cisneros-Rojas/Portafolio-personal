# HanziPlay&Learn

## Categoría

Desarrollo Web / Educación / Gamificación

## Tecnologías

- Laravel 12
- PHP 8.3
- MySQL
- Blade
- Tailwind CSS
- JavaScript
- HanziWriter API

## Descripción Corta

Plataforma web educativa desarrollada con Laravel que utiliza gamificación
y minijuegos interactivos para facilitar el aprendizaje de caracteres chinos,
su pronunciación y significado.

## Descripción

HanziPlay&Learn es una aplicación web orientada al aprendizaje de chino
mandarín mediante una experiencia interactiva basada en la gamificación.
Integra diferentes minijuegos para reforzar el reconocimiento visual de
los caracteres Hanzi, su pronunciación mediante pinyin y su significado.

El proyecto utiliza una arquitectura MVC y aplica principios de SOLID y
Clean Code, con una estructura modular que facilita el mantenimiento y la
incorporación de nuevos juegos y categorías.

## Características

- Arquitectura basada en MVC
- Estructura modular y escalable
- Interfaz moderna y responsiva
- Minijuegos educativos
- Componentes reutilizables
- Integración con HanziWriter API
- Preparado para incorporar nuevos juegos y categorías

## Juegos

### Memory Hanzi

Juego de memoria que relaciona caracteres chinos con su pinyin o significado
para reforzar la asociación entre escritura y vocabulario.

### Stroke Quiz

Ejercicios interactivos para practicar el orden correcto de los trazos de
los caracteres chinos mediante HanziWriter.

### Catch the Character

Juego de reconocimiento rápido en el que el usuario identifica caracteres
pertenecientes a una categoría mientras aparecen en pantalla. Registra
aciertos, errores, precisión y tiempo de respuesta.

## Arquitectura

El proyecto utiliza una arquitectura MVC que separa la presentación, la
lógica de negocio y el acceso a datos. Su estructura modular permite
incorporar nuevos minijuegos y funcionalidades reutilizando componentes
y servicios existentes.
